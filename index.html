RelayCanvas

siap

Klik komponen di kiri lalu klik kanvas. Kabel: tombol Kabel, klik pin lalu pin lain. R rotasi, Del hapus, Esc batal. Klik tengah lalu tarik untuk geser kanvas.

Pintasan dan cara pakai

  • Klik tombol komponen lalu klik kanvas untuk menaruh.
  • Klik komponen untuk memilih, tarik untuk memindah.
  • Tarik di area kosong untuk seleksi kotak.
  • Klik tengah lalu tarik untuk menggeser kanvas.
  • Pilih rail lalu tarik bulatan di ujungnya untuk memanjangkan.
  • Ctrl+scroll mouse zoom in/out kanvas (scroll biasa menggulir).
  • Ekspor menyimpan kanvas ke PNG.
  • R rotasi 90 derajat.
  • Del atau Backspace hapus.
  • Ctrl+Z undo.
  • Ctrl+C / Ctrl+V / Ctrl+D salin, tempel, duplikat.
  • Ctrl+A pilih semua.
  • Label untuk catatan di kanvas; edit teks di panel.
  • W alat kabel, V alat pilih, Esc batal.
  • Kabel: alat Kabel, klik pin lalu pin lain. Tap ke rail atau ke kabel lain otomatis.
  • Klik saklar sekali untuk menutup atau membuka.
  • Run menjalankan simulasi, Pause menghentikan simulasi, Reset mereset simulasi.
  • Simpan / Muat berkas .rly.
